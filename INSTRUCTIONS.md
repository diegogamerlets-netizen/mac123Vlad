# Что нужно сделать вам, чтобы сайт заработал по-настоящему

## 0. Создание макетов: OpenAI (подключено)

Ключ лежит в файле `.env` (`OPENAI_API_KEY`), `AI_PROVIDER=openai`. Подписка ChatGPT Plus для этого не используется: сайту нужен именно API-ключ с platform.openai.com, он оплачивается отдельно по факту использования.

- Один заказ = 4 картинки (вид спереди, справа, сзади, слева) плюс небольшие запросы автопроверки. Время обычно несколько минут.
- Модель, качество и проверяющая модель меняются в `.env` (`OPENAI_IMAGE_MODEL`, `OPENAI_IMAGE_QUALITY`, `OPENAI_QA_MODEL`).
- Следите за расходом и балансом на platform.openai.com. Лимит `GEN_LIMIT_PER_HOUR` защищает от лишних трат.
- Серверы OpenAI находятся в США. Фото граждан уходят за границу: см. примечание про Роскомнадзор в политике конфиденциальности.
- Ключ не публикуйте и не пересылайте. Если он где-то засветился, отзовите его в кабинете OpenAI и создайте новый.

## 1. Нейросеть для макетов (ChatGPT / OpenAI)

**Главное:** подписка ChatGPT Plus не даёт доступа к API. Это два отдельных продукта. Сайту нужен API-ключ с платформы OpenAI (platform.openai.com), он оплачивается отдельно, по факту использования.

Шаги:
1. Зарегистрируйтесь на https://platform.openai.com (отдельно от аккаунта ChatGPT).
2. Раздел Billing → пополните баланс (предоплата, начните с небольшой суммы).
3. Раздел API keys → Create new secret key → скопируйте ключ.
4. Для модели `gpt-image-1` OpenAI может потребовать подтверждение организации (Settings → Organization → Verify).
5. В `.env` вставьте `OPENAI_API_KEY=sk-...` и перезапустите сервер.

Важные ограничения:
- **Россия.** OpenAI официально не работает в России: нет регистрации по российским номерам и оплаты российскими картами. Проверьте, доступно ли вам это легально и технически. Если нет, нужна другая нейросеть. Подключается в `ai.py`, функции `_call_openai` достаточно подменить на вызов другого сервиса.
- **Цена.** Одна генерация = 4 изображения. Точную цену смотрите на странице цен OpenAI (зависит от качества `OPENAI_IMAGE_QUALITY`). Прикиньте, сколько стоит попытка клиента, помня, что часть клиентов не оплатит заказ. Лимит `GEN_LIMIT_PER_HOUR` ограничивает попытки с одного IP.
- **Фото клиентов уходят на серверы OpenAI.** Это нужно описать в политике обработки персональных данных (`/legal`). Для российских клиентов это передача данных за границу, проконсультируйтесь с юристом (152-ФЗ).
- Качество «одинаковости» фигурки с разных сторон нужно проверить на реальных фото. Если не устроит, поправьте промпты в `ai.py`.

## 2. ЮKassa

1. Зарегистрируйтесь на https://yookassa.ru и подайте заявку на подключение магазина. Нужен статус ИП, самозанятого или юрлица (физлица без статуса не подключают).
2. В анкете укажите адрес сайта. Сайт должен быть доступен по https и содержать: описание товара с ценой, контакты и реквизиты, условия доставки и возврата, оферту. Всё это — страница `/legal` (заполните её).
3. Дождитесь одобрения. До этого можно тестировать в **тестовом магазине** (создаётся в кабинете, платежи не настоящие, тестовые карты в документации ЮKassa).
4. Кабинет → Интеграция → Ключи API: скопируйте **shopId** и **секретный ключ** в `.env` (`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`). Для теста сначала вставьте ключи тестового магазина.
5. Кабинет → Интеграция → HTTP-уведомления: адрес `https://ваш-домен.ru/api/yookassa/webhook`, событие `payment.succeeded` (желательно и `payment.canceled`).
6. Чеки по 54-ФЗ: если вы ИП/юрлицо на ККТ, в кабинете подключите чеки от ЮKassa и в `.env` задайте `YOOKASSA_TAX_SYSTEM` и `YOOKASSA_VAT_CODE`. Самозанятые чеки формируют в «Мой налог», тогда поставьте `YOOKASSA_RECEIPT=0` (уточните в поддержке ЮKassa).
7. В `.env` задайте `BASE_URL=https://ваш-домен.ru` — на этот адрес покупатель вернётся после оплаты.
8. Сделайте тестовый платёж: заказ → оплата тестовой картой → страница «Оплата прошла». Затем замените ключи на боевые.

## 3. Проверка адреса (DaData)

Без этого адрес не проверяется. Сейчас в форме работает подсказка и проверка существования дома по ФИАС (через DaData).

1. Зарегистрируйтесь на https://dadata.ru, подтвердите email.
2. В личном кабинете скопируйте **API-ключ**.
3. В `.env`: `DADATA_TOKEN=ваш_ключ`.
4. Бесплатно — до 10 000 запросов в сутки на подсказки (проверьте актуальные условия на dadata.ru).

После этого покупатель может выбрать только существующий адрес из списка до номера дома. Сервер перепроверяет адрес при расчёте доставки и при создании заказа.

## 4. Доставка

Сейчас в коде подключён **СДЭК** (автоматический расчёт цены курьерской доставки до двери). Цена доставки платится покупателем сверх стоимости скульптуры и входит в общую оплату через ЮKassa отдельной строкой чека.

### СДЭК
1. Заключите договор интернет-магазина: https://lk.cdek.ru → «Интеграция» (или через менеджера СДЭК).
2. В личном кабинете: Интеграция → Ключи API. Получите `Account` (client_id) и `Secure password` (client_secret).
3. В `.env`: `CDEK_CLIENT_ID`, `CDEK_CLIENT_SECRET`, `CDEK_FROM_POSTCODE` (индекс, откуда вы отправляете), габариты упаковки `PACKAGE_*`.
4. Тестовая среда СДЭК: `CDEK_API_URL=https://api.edu.cdek.ru/v2` (тестовые ключи есть в документации API СДЭК на https://apidoc.cdek.ru). После проверки уберите эту строку.
5. Что **не** автоматизировано: создание накладной и вызов курьера. Пока вы оформляете отправку в личном кабинете СДЭК вручную по данным из `/admin`. Следующий шаг — вызов `POST /v2/orders` из кода.

> Код расчёта СДЭК написан по документации API v2, но проверить его на реальном аккаунте я не мог. Первый запуск делайте на тестовой среде и сверьте цену с калькулятором на сайте cdek.ru.

### Другие службы (не подключены, как добавить)
- **Яндекс Доставка** — кабинет https://dostavka.yandex.ru → Интеграции → «Получить токен»; есть API для расчёта и карта пунктов выдачи.
- **Почта России** — API для интернет-магазинов (otpravka.pochta.ru), нужен договор и токен.
- **Boxberry, 5Post** и др. — у каждой свой договор и API.
- Альтернатива: агрегатор доставки (одна интеграция вместо нескольких), например через сервисы вроде Cargo.ru или модули в CMS. Условия и тарифы смотрите у самих сервисов.

Чтобы добавить службу, в `delivery.py` напишите функцию, возвращающую список вариантов `{id, provider, name, price, days}`, и вызовите её в `quote()`. Форма на сайте покажет варианты сама. Пункты выдачи (самовывоз с картой) пока не реализованы: для них нужен виджет выбора пункта.

## 5. Размещение и запуск на хостинге

Нужен VPS или хостинг с Python 3.9+ (не обычный PHP-хостинг). Запуск: `python server.py` за nginx с https (Let's Encrypt), автозапуск через systemd. Папка `data/` содержит заказы и фото — делайте её резервные копии и не публикуйте.

## 6. Юридически перед запуском

- Заполните `/legal`: реквизиты, материал и способ изготовления, сроки, возврат, политику персональных данных.
- Формулировки на сайте («мастерская», «наши мастера воплощают») не должны вводить в заблуждение. Не утверждайте «ручная работа», если это не так.
