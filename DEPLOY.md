# Перенос сайта на сервер Selectel и подключение домена

Схема: **облачный сервер (VPS) Selectel** → nginx (HTTPS) → приложение `server.py`. Сервер в России, так что данные покупателей хранятся на территории РФ (152-ФЗ).

## Что делаете вы (≈10 минут, оплата только у вас)

### 1. Сервер в панели Selectel
1. Панель my.selectel.ru → **Облачная платформа** → создайте проект (если нет) → **Облачные серверы → Создать сервер**.
2. Параметры:
   - Регион и пул: любой российский (Москва / Санкт-Петербург).
   - Образ: **Ubuntu 24.04 LTS** (подойдёт и 22.04).
   - Конфигурация: **1 vCPU, 2 ГБ RAM**, диск **30 ГБ** (сайт лёгкий, но каждая генерация макета занимает около 8 МБ; старые автоматически чистятся).
   - Сеть: **публичный IPv4-адрес** (плавающий IP: он не пропадёт при пересоздании сервера).
   - **SSH-ключ:** добавьте публичный ключ, который я вам дал (строка начинается с `ssh-ed25519 …`). Пароль root не нужен, вход только по ключу.
   - Группа безопасности (если спросит): разрешить порты **22, 80, 443**.
3. Нажмите «Оплатить / Создать» (цену покажет калькулятор панели). Дальше дождитесь статуса «Активен».
4. Пришлите мне **IP-адрес сервера**.

### 2. DNS: домен → сервер
В панели Selectel: **Домены → ваш домен → DNS-хостинг → Записи**. Создайте записи:
| Тип | Имя | Значение |
|---|---|---|
| A | `@` (сам домен) | IP сервера |
| A | `www` | IP сервера |

Обновление занимает от нескольких минут до пары часов. Сообщите мне, когда сделали, я проверю.

## Что делаю я (по SSH-ключу, без ваших паролей)
1. `bash deploy/deploy.sh root@IP` — загрузка файлов сайта.
2. `setup.sh` на сервере: nginx, служба `oblik` (автозапуск, перезапуск при сбое), файрвол (22/80/443), ежедневная очистка старых макетов и резервные копии заказов.
3. Боевой `.env` (шаблон: `deploy/.env.production.example`): `BASE_URL`, `HOST=127.0.0.1`, пароль админки, ключи. Секреты вы вносите сами или передаёте безопасным способом.
4. HTTPS: сертификат Let's Encrypt (`certbot`), автопродление.
5. Проверка: главная, форма заказа, админка, демо-оплата.

## После запуска, что нужно сделать вам
- **ЮKassa:** в кабинете → Интеграция → HTTP-уведомления: `https://ваш-домен/api/yookassa/webhook`, событие `payment.succeeded`. Сначала тестовый магазин.
- Заполнить жёлтые поля в оферте и политике (адрес ИП, email) и удалить плашку «Черновик» (она исчезнет сама).
- Роскомнадзор (уведомление об обработке персональных данных, и о трансграничной передаче, если фото уходят в OpenAI).
- Раз в неделю скачивать резервную копию к себе (команду дам) или включить резервное копирование диска в панели.

## Обновление сайта позже
`bash deploy/deploy.sh root@IP` загружает новые файлы и перезапускает службу. Файл `.env` и папка `data` (заказы, макеты) при этом не затрагиваются.

## Полезные команды на сервере
```
systemctl status oblik          # состояние
journalctl -u oblik -n 100      # логи приложения
nginx -t && systemctl reload nginx
python3 /opt/oblik/app/cleanup.py --dry-run   # что удалила бы очистка
```
