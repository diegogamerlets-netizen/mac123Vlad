# Облик

Сайт заказа статуэтки по фото. Python 3.9+, внешних библиотек нет.

## Запуск

```
py server.py
```

Откройте http://localhost:8000. Без ключей работает демо-режим: вместо нейросети показывается исходное фото, вместо ЮKassa — страница-заглушка оплаты.

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

- `OPENAI_API_KEY` — включает реальную генерацию макетов (см. `ai.py`; другую нейросеть можно подключить там же).
- `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` — включают настоящую оплату.
- `PRICE_ONE_PERSON`, `PRICE_TWO_PEOPLE`, `PRICE_STEP` — цены; `DADATA_TOKEN` — проверка адреса; `CDEK_*` — доставка. Подробно: INSTRUCTIONS.md.
- `ADMIN_PASSWORD` — включает страницу заказов `/admin`.

## Оплата ЮKassa на хостинге

1. В `BASE_URL` укажите адрес сайта с https.
2. В личном кабинете ЮKassa → Интеграция → HTTP-уведомления добавьте `https://ваш-домен/api/yookassa/webhook` (событие `payment.succeeded`). Статус заказа также проверяется при открытии страницы заказа.
3. Заполните `/legal` (templates/legal.html): реквизиты, оферта, возврат.

## Где что лежит

- `server.py` — маршруты, заказы, админка
- `ai.py` — генерация 4 ракурсов
- `yookassa.py` — платежи
- `templates/`, `static/` — страницы, стили, скрипты
- `data/` — заказы (`orders.json`) и сгенерированные макеты (создаётся сам; не публикуется)
